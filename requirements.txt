# =============================================================================
#  3D Gaussian Splatting Reconstruction — 依赖清单
# =============================================================================
#
#  ⚠️ 请勿直接执行 `pip install -r requirements.txt`！
#     原因：PyTorch 需要指定 CUDA 版本，OpenCV 需要用 headless 版本。
#
#  请按以下步骤依次安装：
#
#  1. 创建 conda 环境（必须 Python 3.11）
#     conda create -n gs python=3.11
#     conda activate gs
#
#  2. 安装 PyTorch（CUDA 12.1 版本，CPU 用户请去掉 cu121 后缀）
#     pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
#
#  3. 安装 OpenCV（必须用 headless 版本，避免 Qt 冲突）
#     pip install opencv-python-headless
#
#  4. 安装其余核心依赖
#     pip install numpy scipy PySide6 matplotlib
#
#  5. （可选）安装 CUDA 光栅化器（需 VS2022 生成工具 + CUDA Toolkit）
#     pip install git+https://github.com/graphdeco-inria/diff-gaussian-rasterization
#
#  6. （可选）COLMAP 后端支持——需要额外下载 COLMAP 二进制文件
#     项目已附带 colmap-x64-windows-nocuda/，无需 pip 安装任何包
#
#  7. （实验性）LPIPS 感知损失——代码中有支持但默认未启用
#     # pip install torchmetrics
# =============================================================================
